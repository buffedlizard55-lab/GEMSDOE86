What the GEMSDOE32 H33-2-B2 record shows

The owner repository describes a post-processing operation: delete predicted dots within 200 m of mapped catalogue traces from an earlier raster. That can help only if the removed mass was mostly false-positive or redundant; it can also erase real unmapped splays. It is a spatial pruning heuristic, not a new geological signal.

The pinned owner manifest lists the artifact as PRIMARY, but its organizer-receipt field is empty and the site's own note calls it UNSCORED. The value quoted in the request is not corroborated by an organizer receipt. The owner page's holdout/projection material is not a protocol-compliant HOLDOUT-DTI result: evaluator version, withheld-positive count, and spatial 95% interval are missing. Therefore we cannot say that the file scored the claimed value, why it would have done so, or that GEMSDOE86 can beat it.
