Project principles

Maximize P(Win). Own the Outcome.

Move quickly on hypotheses, slowly on claims. The weekly-slot selector remains independent of the research run.

Scientific gates

Whole fault components are withheld with a feature-context buffer. Catalogue features come from visible faults only; visible fault pixels are masked exactly. Each feature is tested alone for leakage before a candidate is judged.

Artifact gates

Check both surface and final-raster uniqueness against a complete registry index. A passing holdout is not a submission; the shared writer and validator receipt must pass before any download is enabled.
