Before a file can be released

  1. Confirm the assigned single-method lane and reuse the pinned shared feature cache.
  2. Test each feature's leakage canary on whole-segment buffered holdouts. Derive catalogue features only from visible faults.
  3. Beat the comparable incumbent using the shared pooled HOLDOUT-DTI evaluator; report version, withheld positives, spatial 95% CI and paired improvement uncertainty.
  4. Compare the surface before placement and final dots against every registry raster. Stop on rank correlation above 0.90 or more than 70% of dots within 3 pixels of any registry raster. Missing references are not a pass.
  5. Export through the unmodified shared writer. Reject NaN, Inf, sentinels and out-of-range values rather than clipping. Require a single band, values in [0,1], and exact sample CRS, shape and geotransform; verify again after serialization and record SHA256.
  6. A separate selector checks authenticated weekly quota and authorizes the file for a real slot. Local format validity is not organizer acceptance.

Portal steps — after authorization only

  1. Download the authorized .tif, or a ZIP containing only that one TIFF, from the future release panel. Verify its name and SHA256 against the adjacent receipt.
  2. Open the official competition, sign in, confirm eligibility/rules and the remaining submission quota, then choose “New submission.”
  3. Choose the authorized prediction file. Do not choose a research report, audit JSON, sample submission or copied historical raster.

  5. Submit once, retain the organizer's acceptance/score receipt and bind it to the file SHA. Only that evidence may be called ORGANIZER-CONFIRMED.
