Gates a file must pass before anyone submits it

  1. Lane & provenance: single declared method; data hash-pinned; catalogue never used as a predictor.
  2. Leakage canary: every feature alone on the buffered whole-segment holdout; AUC >0.90 = leakage until proven otherwise.
  3. Holdout skill: pooled HOLDOUT-DTI (α=0.2, β=0.8, 300 m triangular) must beat the incumbent benchmark on the identical shared evaluator path, with withheld-positive count and spatial-block 95% CI reported. The prior H86 values are diagnostic only: its script used holdout.evaluate and cell-bootstrap intervals, not evaluate_holdout.evaluate and physical-block uncertainty; those values cannot authorize promotion.
  4. Uniqueness: surface (pre-placement) and final dots vs registry: stop on Spearman ρ >0.90 or >70% dots within 3 px of one raster; literal firings (e.g. saturating lattices) are logged, not hidden; incomplete registry = stated scope limit, never “clearance”.
  5. Format: shared submission_writer only; serialized file re-validated; SHA-256 recorded.
  6. Selector step: a separate human/selector checks the live weekly quota on the authenticated submission page and authorizes the slot. Local PASS ≠ organizer acceptance.
