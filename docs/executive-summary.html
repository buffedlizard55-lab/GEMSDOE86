Release gates — all must pass before a TIFF is offered

  1. Resolve the assigned single-method lane and reuse the pinned shared feature cache. Do not infer a lane from unrelated repositories or choose a hypothesis by yourself.
  2. Freeze whole-segment, spatially buffered hide-and-recover folds. Derive all catalogue-based features from visible faults only and mask visible faults pixel-exactly.
  3. Run a leakage canary for each feature alone. An AUC above 0.90 is a stop-and-investigate signal, not evidence of scientific skill.
  4. Compare a candidate and incumbent on identical folds using the shared pooled HOLDOUT-DTI evaluator. Report evaluator version, withheld positives, spatial 95% CI, and paired difference CI. The required objective uses alpha 0.2, beta 0.8, and a 300 m triangular tolerance.
  5. Compare the feature surface before placement and the final dots against every pinned registry raster. Stop if rank correlation exceeds 0.90 or more than 70% of dots fall within 3 pixels of a registry raster. An incomplete registry is not a uniqueness pass.
  6. Export only through the unmodified shared writer. Re-read the serialized TIFF and verify one float32 band, no NaN/Inf within the footprint, values in [0,1], and exact sample CRS, shape, and geotransform. Record the SHA256 and an honest receipt.
  7. Only after scientific and technical gates pass may a separate selector check the authenticated weekly quota and authorize a real slot. Do not auto-submit or interpret a local format PASS as organizer acceptance.
