What is checked without intervention?

  • Every published TIFF is decoded and checked by the pinned shared validator and template-format checker.
  • CRS, shape, affine transform, float32 band count, valid footprint, finite values in range, outside-footprint zeros and mapped-fault masking are measured from disk.
  • The SHA matches the inventory, writer receipt and applicable scientific card. ZIP bytes must contain exactly the corresponding TIFF; empty or mismatched ZIPs fail.
  • Names and notes are verified against the project length cap. Stored model evidence is not rewritten or upgraded by a format pass.
  • All final artifacts are bound to the negative registry measurement. Unknown/missing/stale evidence fails closed.

Registry checks must fail closed

Candidate checks reject invalid values rather than thresholding or masking them into validity. Missing or invalid registry files, empty/constant predictions and stale candidate evidence cannot pass. Current reports bind the exact source array, decoded pixels and indexed registry content. A surface check runs before dot placement; final-dot checks precede TIFF generation. Historical unbound reports are archives, not clearance, and must be rerun. The representation-aware diagnostics are not permission to ignore the literal stop or spend a slot.

Independent code review, research sketches and limitations

Future submission steps — only after scientific clearance

  1. Resolve the protocol conflict first. A new lane must be authorized, the actual shared cached features and a complete accessible registry recovered, and the uniqueness rule made satisfiable through an explicit protocol revision. This project does not grant that revision itself.
  2. Validate a new method. Freeze whole-segment buffered folds, derive catalogue features only from visible faults, run each feature's leakage canary, and beat the strongest rerunnable matched control with a positive paired physical-block confidence interval. Use the shared evaluator and writer unchanged.
  3. Run all release checks. A format pass alone is insufficient: both pre-placement surface and final-dot uniqueness must pass the literal thresholds. Promotion is separate from slot selection.
  4. Use the separate selector. It must inspect the authenticated submission page's actual remaining weekly quota and bind its decision to the exact raster SHA. The public rules list 3 submissions per week; that is not our current account balance. No account credentials or automatic upload are implemented here.
  5. Download only the authorized TIFF or one-TIFF ZIP. Choose New submission on the official submission page, select the file (not JSON, a sample or an audit-only artifact), and paste its short identity note.
  6. Retain the organizer receipt. Bind the result and submission ID to the exact SHA before classifying any score as ORGANIZER-CONFIRMED. Follow the rules for one final selection, reproducible assets, eligibility and generative-AI disclosure.

The reported “[0,1]” rejection

The rejected file was not supplied, so the cause is unknown. The shared writer rejects nonfinite and out-of-range predictions instead of silently clipping them, then validates the serialized output and ZIP. The current audit rechecks those bytes. This prevents us publishing that class of invalid numerical output, but it does not prove portal acceptance.

The public specification describes null/NaN outside bounds. The project's all-finite, zero-outside policy is a conservative local choice. It must not be described as organizer-confirmed acceptance or a complete diagnosis of the earlier error.
