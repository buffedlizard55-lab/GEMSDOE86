Gates a file must pass before anyone submits it

  1. Lane & provenance: single declared method; data hash-pinned; catalogue never used as a predictor.
  2. Leakage canary: every feature alone on the buffered whole-segment holdout; AUC >0.90 = leakage until proven otherwise.
  3. Holdout skill: pooled HOLDOUT-DTI (α=0.2, β=0.8, 300 m triangular) must beat the incumbent benchmark on the identical evaluator, with withheld-positive count and 95% CI reported. This candidate failed here.
  4. Uniqueness: surface (pre-placement) and final dots vs registry: stop on Spearman ρ >0.90 or >70% dots within 3 px of one raster; literal firings (e.g. saturating lattices) are logged, not hidden; incomplete registry = stated scope limit, never “clearance”.
  5. Format: shared submission_writer only; serialized file re-validated; SHA-256 recorded.
  6. Selector step: a separate human/selector checks the live weekly quota on the authenticated submission page and authorizes the slot. Local PASS ≠ organizer acceptance.

Portal steps (green-lit files only)

  1. Download the .tif (or the .zip containing only that TIF) from the dashboard; verify SHA-256 against the adjacent receipt.
  2. Go to the official competition, sign in, re-read the rules, confirm remaining weekly quota.
  3. Click New submission → File to submit → choose the verified .tif/.zip (single-band GeoTIFF matching the format CRS/shape/geotransform).
  4. Paste the release note (≤140 chars) into Note so the team can tell submissions apart.
  5. Submit once. Save the organizer's receipt/score page. Only that evidence may be labelled ORGANIZER-CONFIRMED; projections and holdout numbers may never be written as scores.
