Executive summary — how to make a submission

1. Download gems86-gmc-linepost-offcat-90568d-20261022T224539Z-e6f914e4-zeros.tif (or the ZIP next to it — it contains exactly this one GeoTIFF).

2. Go to the submission page and choose File to submit.

3. Paste the note (107 characters, limit 140):

GEMSDOE86 GMC cross-gradient + line-matched posterior; 90568 dots, 3px-spaced, EPSG:32611, all-finite [0,1]

4. Submit. The file is already in the required format: single-band float32 GeoTIFF, 3730 × 3292, EPSG:32611, 100 m, values 0.0/1.0 with no NaN anywhere. If the form returns "Predicted values must be in range [0, 1]", you have uploaded the wrong file — this one has min 0.0 and max 1.0 in every one of the 12,279,160 cells.
