Electrical Conductance Maps of the Great Basin, USA

USGS ScienceBase DOI 10.5066/P9TWT2LU lists five conductance layers spanning depth intervals from 2 km to 200 km, estimated from a 3-D MT model using over 800 publicly available transfer functions. The catalog bounding box contains the coarse screening window. However, an associated surface-layer world file reports 1000/−1000 map-unit pixels and a projected-looking origin, while the raster facet declares EPSG:4269. The internal GeoTIFF CRS/resolution, exact-footprint valid pixels, and a reproducible reprojection remain unchecked.
