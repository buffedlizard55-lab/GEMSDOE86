# GEMSDOE86 hypothesis dossier — preregistration only

**Status: ranked leads; no implementation, holdout, score, or submission.** The accessible comparison of owner-published GEMSDOE32 and GEMSDOE83 materials shows a broad prior-art field. Novelty is necessarily provisional: those public repositories are not a complete organizer registry, and a complete registry index is not present here. The candidates below are new *data/physics combinations relative to the materials inspected*, not claims of globally unprecedented methods.

## Screening rules

A lead is not called viable until (1) its source bytes can be obtained, (2) the source grid’s valid-data mask is checked against the exact competition footprint, (3) the feature can be made label-blind, and (4) the complete registry can be searched. No numerical DTI gain is forecast: without the official training inputs and the pinned evaluator, an estimate would be unsupported. The source screening used the USGS conductance record’s published spatial bounding box and the coarse geographic window used by a prior public USGS query; that window is **not** asserted to be the exact GEMS AOI polygon.

## Prior art exclusions (not GEMSDOE86 hypotheses)

- **USGS ComCat epicenter lineaments / moment-tensor nodal planes** are already proposed as H33-E and H84-E in the inspected owner materials; they are not claimed as novel here.
- **Multi-physics lineament consensus, aligned drainage/valley chains, LiDAR scarplet chains, straight conductivity/basement boundaries** appear in the H33 candidate set. They are excluded from this new shortlist.
- **Submodular/Dinkelbach emitters, structural relay/continuation, GDR geothermometers/vents, GeoDAWN radiometry, lidar scarp features, SGMC filtering, cross-contact magnetic phase displacement, and catalogue-distance pruning** appear in inspected GEMSDOE32/GEMSDOE83 prior work. No copied raster or result is used.
- A thermal-infrared lead exists in earlier geothermal-knowledge notes; Landsat thermal imagery is therefore not presented as a new hypothesis in this dossier.

## H86-B: second-ranked distinct-source lead (not run)

Sentinel-1 repeat-pass interferometry is a separate, high-resolution measurement family. A defensible candidate would require persistent phase/LOS-velocity discontinuity aligned as a linear fault-like structure across multiple acquisitions, never a single-scene edge. The official Copernicus page documents SLC availability outside Europe from February 2021 onward, but no GEMS-footprint scene inventory, orbit-pair coverage, coherence, or account/download test was performed. The principal mimics are atmospheric delay, temporal decorrelation, anthropogenic/groundwater subsidence, and orbit geometry. This lead is **not viable** until the actual scene inventory and usable time-series coverage are verified; it is not the top experiment in this run.

## Top candidate: preregistered validation plan (not run)

1. **Acquire and audit source**: download only the USGS ScienceBase depth-banded rasters; record file URL, byte count, checksum, CRS, transform, pixel size, nodata, and source metadata. Resolve the catalog `EPSG:4269` versus world-file discrepancy from the GeoTIFF’s internal tags before resampling. Align to the sample-submission grid using the project’s declared, reproducible resampling rule. Intersect the *actual* source-valid mask with the exact GEMS footprint; do not infer coverage from the catalog bounding box.
2. **Lock features before seeing hidden labels**: derive an edge-orientation/line-support surface independently for each depth band; combine only after registering the depth-coherence operator, scale range, and weights. Preserve each source-band-only surface as a canary arm.
3. **Leakage tests**: calculate each feature-alone AUC using the shared spatial split. AUC above 0.90 is a leakage alarm and stops the run until explained. Mask visible catalogue pixels pixel-exactly; all catalogue-derived context, if later introduced, must use the fold’s visible mask only.
4. **Hide-and-recover**: use the pinned shared `buffered_component_draw` protocol (whole 8-connected components, not short chopped strands), label-blind quadrant selection, and the shared feature-context buffer. Confirm that the evaluator receives that fold unchanged; record the actual withheld-positive count.
5. **Metric and uncertainty**: use the shared pooled evaluator `gems57-pooled-hide-v2`, DTI `α=0.2`, `β=0.8`, 100 m cells, 300 m triangular kernel; report the pooled paired spatial-block bootstrap 95% CI. No metric is calculated in this repository yet.
6. **Uniqueness and output**: require a complete hash-verified registry index; check rank correlation and 3 px dot overlap on both the continuous surface and final raster. Stop on either duplicate threshold. Only then call the shared writer with the sample grid and persist its receipt plus validator output. A holdout result does not itself promote a weekly slot.
