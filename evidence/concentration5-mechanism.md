# Mechanism cards — CONCENTRATION, 5 km blocks (2026-10-23)

All predictions are **MODEL** reads against USGS SGMC off-catalogue faults, not scores. The three doses and the low→high direction were fixed before those reads. Source: USGS GeoDAWN, https://data.usgs.gov/datacatalog/data/USGS:657e1d85d34e23d3533209f7 (public-domain owner mirror); SGMC control: https://www.usgs.gov/science-plan/conterminus-synthetic-geologic-map-compiler-sgmc.

**Shared hypothesis.** Unmapped faults cluster in 5 km fault-interaction / magnetic-edge blocks more strongly than R0's allocation assumes. **Mechanism.** Move unit dots from lowest-prior blocks to the highest-prior fifth while holding count and spacing fixed. **Non-fault mimic.** Lithologic/intrusive magnetic contacts and catalogue-mapping effort can both create the same block prior without a new fault. **Shared falsifier.** A live change below 0.01 is no evidence; a ≤−0.01 receipt rejects this allocation direction, and CV moving farther above the claimed 0.51–0.59 band is the geometric warning, not a gate.

**Instrument conflict (decision-changing).** The catalogue hide-and-recover PROXY rises with dose, but the independent SGMC MODEL read falls and **0% of every arm's added cells land on the parent's H19-5 support surface**. The PROXY is therefore not used to promote these files: it rewards recovery by a catalogue-derived prior while the placement rule abandons the lineage's rated support. This is a confound and a reason for no 5 km slot, not a claim that the PROXY is a live score.
