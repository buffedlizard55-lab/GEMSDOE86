## Pass 2 — bugs, assumptions and edge cases

The first complete run exposed an input-validity accounting defect: radiometric zero is nodata, but the initial cache cleaner was passed a mask that made missing-in-footprint counts appear as zero and allowed median-filled cells into the mixing regression. This did not produce invalid values, but it weakened provenance and could create coverage-edge artifacts.

The feature builder was corrected to:

- convert radiometric zero to NaN before common cleaning;
- report the actual missing-in-footprint count;
- fit K~Th+U only on the common K/Th/U valid domain;
- use normalized filtering on that domain;
- zero residual-derived features outside that domain.

The cache, both experiments, production model, TIFF, ZIP and every dependent receipt were regenerated after the fix. The final TIFF SHA-256 is `9ed632445228aad8d9b14d8db75d24687520a092e7e14ca94c3151f96f7aafdd`.
