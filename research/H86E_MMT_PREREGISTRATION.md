# H86E-MMT preregistration: non-zero-lag magnetic-marker translation

**Status:** frozen lane design; no organizer score or selector decision.  This document is the scientific preregistration for the three-arm H86E-MMT run. The repository process irregularity is recorded explicitly: the original scaffolding was written before this standalone document was added, so this record must not be described as contemporaneous timestamp proof. No post-hoc result changed the arm definitions, thresholds, holdout split, or dot budget.

**Lane:** H86E-MMT  
**Data:** owner-supplied, SHA-pinned `data/training_features.tif`; competition labels and sample grid are owner mirrors and are not organizer-authenticated.  
**Shared tools:** `vendor/gems57` holdout evaluator, emitter, writer, and registry/PA-86 checkers; no private evaluator fork.  
**Budget:** exactly three arms, 44,090 emitted dots, or two hours, whichever is reached first. No weekly slot is part of this experiment.

## Frozen validation and promotion rules

1. Use the shared buffered whole-component hide-and-recover evaluator with whole fault components hidden, a 3-pixel collar, catalogue features derived only from visible faults, and exact pixel masking of visible faults. Use pooled DTI with `alpha=0.2`, `beta=0.8`, a 300 m triangular kernel, evaluator/version recorded, withheld-positive count recorded, and a 95% CI.
2. Run the single-feature leakage canary before interpreting DTI. A discriminative AUC above `0.90` is leakage until proven otherwise; stop the lane.
3. Compare each arm with the preregistered controls on the same split. Do not call a holdout result an organizer score and do not project it to the leaderboard.
4. Before placement and again on final dots, use `check_h86e_registry.py` and `pa86_chance_overlap.py`. Rank correlation over `0.90` with any registry raster or more than `70%` of dots within 3 px of any registry raster is a hard duplicate stop; an informative PA-86-02 overlap firing is a hard stop. Surface checks are performed before dot placement.
5. Emit only a single-band float32 GeoTIFF on the sample grid. Validate finite values, `[0,1]`, CRS, shape, transform, footprint, catalogue masking, one-TIFF ZIP contents, SHA-256, and registry identity. A format pass is not scientific authorization.
6. A run card must include the hypothesis, mechanism, named non-fault mimic, HOLDOUT-DTI/CI/evaluator, withheld-positive count, leakage canary, registry correlation/overlap, SHA-256, validator output, submission name, note of at most 140 characters, and `promote`/`negative` verdict. Only a separate selector could spend a weekly slot.

The final result is a negative research deliverable if any promotion gate fails. No organizer receipt is created by this lane.
